# ADR-010: Spring Boot 4.1.1 + Java 25

**Fecha:** 2026-09
**Estado:** Aceptada

## Contexto

Actualización del stack backend.

## Decisión

Usar Spring Boot 4.1.1 con Java 25 y Spring Data MongoDB.

## Consecuencias

- ✅ Últimas características de Java
- ✅ Spring Boot 4 con soporte para Java 25
- ✅ Mejoras de rendimiento
- ⚠️ Requiere JDK 25+
