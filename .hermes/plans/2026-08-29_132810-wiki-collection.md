# Wiki-Collection — Plan

## Propósito del Repo

Este repositorio es exclusivamente la **wiki/documentación** del proyecto Wiki-Collection. Backend y frontend tendrán sus propios repos.

## Arquitectura del Proyecto

- **Backend:** Java 17+ + Spring Boot 3.x + Spring Data MongoDB
- **Frontend:** React 18 + Vite
- **Base de datos:** MongoDB
- **APIs externas:** Google Books API (principal) + Open Library (fallback)
