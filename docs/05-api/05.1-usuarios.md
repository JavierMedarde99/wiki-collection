# API — Usuarios

## Estado Actual

No implementado. Planificado para la fase de autenticación.

## Endpoints Planificados

### POST /api/auth/register
Registrar nuevo usuario.

**Request:**
```json
{
  "username": "javi",
  "email": "javi@example.com",
  "password": "securePassword123"
}
```

**Response (201):**
```json
{
  "id": "...",
  "username": "javi",
  "email": "javi@example.com",
  "accessToken": "eyJ...",
  "refreshToken": "eyJ..."
}
```

### POST /api/auth/login
Iniciar sesión.

**Request:**
```json
{
  "username": "javi",
  "password": "securePassword123"
}
```

**Response (200):**
```json
{
  "accessToken": "eyJ...",
  "refreshToken": "eyJ..."
}
```

### GET /api/users/me
Obtener perfil del usuario autenticado.

**Headers:** `Authorization: Bearer <token>`

**Response (200):**
```json
{
  "id": "...",
  "username": "javi",
  "email": "javi@example.com",
  "createdAt": "2024-01-01T00:00:00"
}
```

### PUT /api/users/me
Actualizar perfil del usuario autenticado.

### DELETE /api/users/me
Eliminar cuenta del usuario autenticado.
