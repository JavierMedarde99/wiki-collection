# API — Autenticación

## Estado Actual

No implementado. Planificado para la fase de autenticación.

## Endpoints Planificados

### POST /api/auth/register
Registrar nuevo usuario.

### POST /api/auth/login
Iniciar sesión, devuelve JWT.

### POST /api/auth/refresh
Renovar access token usando refresh token.

**Request:**
```json
{
  "refreshToken": "eyJ..."
}
```

**Response (200):**
```json
{
  "accessToken": "eyJ...",
  "refreshToken": "eyJ..."
}
```

### POST /api/auth/logout
Cerrar sesión (invalida refresh token).
