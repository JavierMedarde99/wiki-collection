## BookService

Implementa `BookUseCase`. Gestiona CRUD de libros.

```java
public interface BookUseCase {
    Page<Book> findAll(Pageable pageable);
    Page<Book> findByStatus(BookStatus status, Pageable pageable);
    Optional<Book> findById(String id);
    Book save(Book book);
    Book update(String id, Book book);
    void delete(String id);
}
```

**Responsabilidades:**
- Validar datos de entrada
- Verificar duplicados (externalId)
- Manejar paginación
- Delegar persistencia al repositorio

## GameSearchService

Implementa `GameSearchUseCase`. Busca juegos en FreeToGame API.

```java
public interface GameSearchUseCase {
    List<GameSearchResult> search(String query);
}
```

**⚠️ Implementación especial:** FreeToGame no soporta búsqueda por nombre, por lo que el servicio:

1. Llama a `GET /api/games` para obtener todos los juegos
2. Filtra por título en memoria usando Java Streams
3. Cachea la lista para evitar llamadas repetidas

```java
public List<GameSearchResult> search(String query) {
    if (query == null || query.isBlank()) {
        return List.of();
    }
    String lowerQuery = query.toLowerCase();
    return cachedGames.stream()
        .filter(g -> g.title().toLowerCase().contains(lowerQuery))
        .toList();
}
```

## GoogleBooksClient

```java
public interface ExternalBookCatalogClient {

}
```
