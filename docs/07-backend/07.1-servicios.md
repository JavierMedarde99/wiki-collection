53|## GameSearchService
54|
55|Implementa `GameSearchUseCase`. Busca juegos con fallback RAWG → FreeToGame.
56|
57|```java
58|public interface GameSearchUseCase {
59|    List<GameSearchResult> search(String query);
60|}
61|```
62|
63|**Implementación:**
64|1. Intenta primero RAWG (búsqueda por nombre nativa)
65|2. Si RAWG devuelve lista vacía, usa FreeToGame como fallback
66|3. No cachea resultados (caché se maneja en el cliente RAWG/FreeToGame)
67|
68|```java
69|public List<GameSearchResult> search(String query) {
70|    if (query == null || query.isBlank()) {
71|        throw new IllegalArgumentException("El parámetro de búsqueda 'name' es obligatorio");
72|    }
73|    List<GameSearchResult> results = rawgClient.search(query);
74|    if (results.isEmpty()) {
75|        return freeToGameClient.search(query);
76|    }
77|    return results;
78|}
79|```

390|## Utilidades y Validators
391|
392|### DeckValidator
393|
394|Valida el estado de un mazo Commander según las reglas del formato.
395|
396|```java
397|public class DeckStatus evaluate(Deck deck) { ... }
398|public List<String> validate(Deck deck) { ... }
399|```
400|
401|**Reglas:**
402|- DRAFT: Mazo en construcción (menos de 100 cartas, sin comandante, etc.)
403|- COMPLETE: Mazo válido (100 cartas, comandante válido, colores correctos)
404|- INVALID: Mazo que no cumple las reglas Commander
405|
406|### DateRangeValidator
407|
408|409|Valida que las fechas de inicio/fin sean coherentes.
410|
411|**Reglas:**
412|- Fechas no pueden ser futuras
413|- Fecha de fin no puede ser anterior a fecha de inicio
414|
415|### PagedResults
416|
417|Utilidad package-private para convertir `List<T>` en `Page<T>` paginada manualmente.

421|## Excepciones
422|
423|| Excepción | HTTP | Uso |
424||-----------|------|-----|
425|| BookNotFoundException | 404 | Libro no encontrado |
426|| BookConflictException | 409 | Conflicto al guardar libro (duplicado) |
427|| GameNotFoundException | 404 | Juego no encontrado |
428|| BoardGameNotFoundException | 404 | Juego de mesa no encontrado |
429|| MagicCardNotFoundException | 404 | Carta Magic no encontrada |
430|| DeckNotFoundException | 404 | Mazo no encontrado |
431|| MovieShowNotFoundException | 404 | Película/serie no encontrada |
432|| MovieShowConflictException | 409 | Conflicto al guardar película/serie (duplicado) |
433|| CatboxUploadException | 502 | Error al subir imagen a Catbox |
434|
435|Todas las excepciones son manejadas por `GlobalExceptionHandler` que devuelve un `ErrorResponse` con timestamp, status, error, message y path.
