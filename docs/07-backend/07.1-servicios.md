## GameSearchService

Implementa `GameSearchUseCase`. Busca juegos con fallback RAWG → FreeToGame.

```java
public interface GameSearchUseCase {
    List<GameSearchResult> search(String query);
}
```

**Implementación:**
1. Intenta primero RAWG (búsqueda por nombre nativa)
2. Si RAWG devuelve lista vacía, usa FreeToGame como fallback
3. No cachea resultados (caché se maneja en el cliente RAWG/FreeToGame)

```java
public List<GameSearchResult> search(String query) {
    if (query == null || query.isBlank()) {
        throw new IllegalArgumentException("El parámetro de búsqueda 'name' es obligatorio");
    }
    List<GameSearchResult> results = rawgClient.search(query);
    if (results.isEmpty()) {
        return freeToGameClient.search(query);
    }
    return results;
}
```

## Clientes Externos

### GoogleBooksClient

Implementa `ExternalBookCatalogClient`. Cliente para Google Books API.

```java
public interface ExternalBookCatalogClient {
    List<BookSearchResult> search(String query);
}
```

**Características:**
- Usa `RestClient` para llamadas HTTP
- Búsqueda con `intitle:` + `langRestrict=es` + `maxResults=10`
- Reintentos: 4 intentos totales con intervalo de 1 segundo
- Propaga excepciones si todos los intentos fallan
- **Cache:** `@Cacheable("bookSearch")`

### RAWGClient

Implementa `ExternalGameCatalogClient`. Cliente para RAWG API.

```java
public interface ExternalGameCatalogClient {
    List<GameSearchResult> search(String query);
}
```

**Características:**
- Usa `RestClient` para llamadas HTTP
- Mapeo de plataformas limitado (PC, PS2, PS3, WII_U, SWITCH)
- Manejo de errores: devuelve lista vacía si falla
- **Cache:** `@Cacheable("gameSearch")`

### FreeToGameClient

**Características:**
- Usa `RestClient` para llamadas HTTP
- Mapeo de plataforma: solo detecta PC
- Manejo de errores: devuelve lista vacía si falla
- **Cache:** `@Cacheable("gameSearch")` (compartida con RAWG)

### BggXmlClient

- Manejo de errores: devuelve lista vacía si falla

## Utilidades y Validators

### DeckValidator

Valida el estado de un mazo Commander según las reglas del formato.

```java
public class DeckStatus evaluate(Deck deck) { ... }
public List<String> validate(Deck deck) { ... }
```

**Reglas:**
- DRAFT: Mazo en construcción (menos de 100 cartas, sin comandante, etc.)
- COMPLETE: Mazo válido (100 cartas, comandante válido, colores correctos)
- INVALID: Mazo que no cumple las reglas Commander

### DateRangeValidator

Valida que las fechas de inicio/fin sean coherentes.

**Reglas:**
- Fechas no pueden ser futuras
- Fecha de fin no puede ser anterior a fecha de inicio

### PagedResults

Utilidad package-private para convertir `List<T>` en `Page<T>` paginada manualmente.

## Excepciones

| Excepción | HTTP | Uso |
|-----------|------|-----|
| BookNotFoundException | 404 | Libro no encontrado |
| BookConflictException | 409 | Conflicto al guardar libro (duplicado) |
| GameNotFoundException | 404 | Juego no encontrado |
| BoardGameNotFoundException | 404 | Juego de mesa no encontrado |
| MagicCardNotFoundException | 404 | Carta Magic no encontrada |
| DeckNotFoundException | 404 | Mazo no encontrado |
| MovieShowNotFoundException | 404 | Película/serie no encontrada |
| MovieShowConflictException | 409 | Conflicto al guardar película/serie (duplicado) |
| CatboxUploadException | 502 | Error al subir imagen a Catbox |

Todas las excepciones son manejadas por `GlobalExceptionHandler` que devuelve un `ErrorResponse` con timestamp, status, error, message y path.
