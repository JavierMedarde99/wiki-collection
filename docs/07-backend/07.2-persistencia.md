# Persistencia

## Spring Data MongoDB

Se usa Spring Data MongoDB para la capa de persistencia.

### Repositorios

```java
public interface SpringDataBookRepository extends MongoRepository<BookEntity, String> {
    Optional<BookEntity> findByExternalId(String externalId);
}

public interface SpringDataGameRepository extends MongoRepository<GameEntity, String> {
    Optional<GameEntity> findByExternalId(String externalId);
}

public interface SpringDataBoardGameRepository extends MongoRepository<BoardGameEntity, String> {

}

public interface SpringDataMagicCardRepository extends MongoRepository<MagicCardEntity, String> {
    // No tiene métodos adicionales
}
```

### Adaptadores

```java
public class BookPersistenceAdapter implements BookRepository {
    private final SpringDataBookRepository springDataBookRepository;
    private final MongoTemplate mongoTemplate;
    private final BookEntityMapper mapper;

    @Override
    public Page<Book> search(BookSearchCriteria criteria, Pageable pageable) {
        Query query = buildQuery(criteria);
        long total = mongoTemplate.count(query, BookEntity.class);
        query.with(pageable);
        List<Book> content = mongoTemplate.find(query, BookEntity.class).stream()
                .map(mapper::toDomain)
                .toList();
        return new PageImpl<>(content, pageable, total);
    }

    private Query buildQuery(BookSearchCriteria criteria) {
        Query query = new Query();
        if (criteria.hasName()) {
            query.addCriteria(Criteria.where("title").regex(ciPattern(criteria.name())));
        }
        if (criteria.hasAuthor()) {
            query.addCriteria(Criteria.where("author").regex(ciPattern(criteria.author())));
        }
        if (criteria.type() != null) {
            query.addCriteria(Criteria.where("type").is(criteria.type()));
        }
        if (criteria.state() != null) {
            query.addCriteria(Criteria.where("state").is(criteria.state()));
        }
        return query;
    }

    private Pattern ciPattern(String value) {
        return Pattern.compile(Pattern.quote(value), Pattern.CASE_INSENSITIVE | Pattern.UNICODE_CASE);
    }
}
```

**Nota:** `GamePersistenceAdapter`, `BoardGamePersistenceAdapter` y `MagicCardPersistenceAdapter` siguen el mismo patrón pero con sus respectivos criterios.

## Configuración MongoDB

```properties
# application.properties
spring.mongodb.uri=mongodb://user:***@127.0.0.1:27017/?authSource=admin&directConnection=true
spring.mongodb.database=collection
spring.data.mongodb.auto-index-creation=false
```

**Nota:** La propiedad correcta es `spring.mongodb.uri` (no `spring.data.mongodb.uri`).

## Auditoría

```java
@Configuration
@EnableMongoAuditing
public class MongoAuditConfig {
}
```

**⚠️ Importante:** Solo hay una clase con `@EnableMongoAuditing`. No añadir otra en el main o en otra configuración porque causa `BeanDefinitionOverrideException`.

## Colecciones MongoDB

- **BOOKS** — Colección de libros
- **GAMES** — Colección de juegos
- **BOARD_GAMES** — Colección de juegos de mesa
- **MAGIC_CARDS** — Colección de cartas Magic

## Búsquedas con MongoTemplate

Las búsquedas se hacen con `MongoTemplate` + `Query` en lugar de derivar nombres de método de Spring Data. Esto permite:
- Búsqueda case-insensitive con regex
- Filtros dinámicos (solo se añaden criterios si tienen valor)
- Paginación con `Pageable`
