# Persistencia

## Spring Data MongoDB

Se usa Spring Data MongoDB para la capa de persistencia.

### Repositorios

```java
public interface SpringDataBookRepository extends MongoRepository<BookEntity, String> {
    Page<BookEntity> findByStatus(BookStatus status, Pageable pageable);
    Optional<BookEntity> findByExternalId(String externalId);
}

public interface SpringDataGameRepository extends MongoRepository<GameEntity, String> {
    Page<GameEntity> findByStatus(GameStatus status, Pageable pageable);
    Optional<GameEntity> findByExternalId(String externalId);
}
```

### Adaptadores

```java
public class BookPersistenceAdapter implements BookRepository {
    private final SpringDataBookRepository repository;
    private final BookEntityMapper mapper;
    
    @Override
    public Optional<Book> findById(String id) {
        return repository.findById(id).map(mapper::toDomain);
    }
    
    @Override
    public Book save(Book book) {
        BookEntity entity = mapper.toEntity(book);
        BookEntity saved = repository.save(entity);
        return mapper.toDomain(saved);
    }
    // ...
}
```

## Configuración MongoDB

```properties
# application.properties
spring.data.mongodb.uri=${SPRING_MONGODB_URI:mongodb://localhost:27017/wiki_collection}
spring.data.mongodb.auto-index-creation=true
```

## Índices Automáticos

Spring Data MongoDB crea índices automáticamente para:
- `@Id` — Primary key
- `@Indexed(unique=true)` — Índices únicos (externalId)
- `@Indexed` — Índices para filtros (status, state)
