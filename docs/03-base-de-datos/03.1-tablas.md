152|## Imágenes (fase 6)
153|
154|155|Las imágenes se almacenan en **Catbox.moe** (hosting externo), no en el filesystem local.
156|
157|**Flujo:**
158|1. Cliente sube imagen vía `POST /api/v1/images/upload`
159|2. Backend valida (5MB máximo, MIME permitido, magic bytes)
160|3. Backend sube a Catbox vía `CatboxClient`
161|4. Backend devuelve `ImageResponse` con `url` y `filename`
162|5. URL se almacena en el campo de imagen de cada entidad (`frontpage`, `thumbnailUrl`, `posterUrl`, etc.)
163|6. Para eliminar: `DELETE /api/v1/images/{filename}` → elimina de Catbox
164|
165|**Archivos relacionados:**
166|- `ImageStorageController.java` — Controlador REST
167|- `CatboxClient.java` — Cliente API Catbox
168|- `ImageStorageService.java` — Servicio de validación + upload
169|- `ImageResponse.java` — DTO de respuesta
170|- `CatboxUploadException.java` — Excepción si falla el upload (HTTP 502)
171|
172|**Nota:** La configuración `app.image.storage.path` ya no se usa (era para filesystem local).
