# Componentes

## Componentes de Libros

### BookCard
Tarjeta de libro para listados.

**Props:**
- `book` — Objeto libro (tipo `Book`)
- `index` — Número para animación escalonada (opcional)

### BookForm
Formulario reutilizable para crear/editar libros.

**Props:**
- `initial` — Datos iniciales parciales (edición)
- `submitLabel` — Texto del botón de envío
- `onSubmit` — Callback al guardar (retorna Promise)
- `error` — Mensaje de error externo (opcional)
- `isCreate` — Si es modo creación (muestra campos de portada/ID externo en edición)

### StatusBadge
Badge de estado del libro.

**Props:**
- `state` — Estado (TO_READ, READING, COMPLETED)

### StarRating
Componente de puntuación por estrellas.

**Props:**
- `value` — Valor 0-5
- `onChange` — Callback al cambiar (opcional)
- `readOnly` — Solo lectura

### ConfirmDialog
Diálogo de confirmación reutilizable.

**Props:**
- `open` — Visible/oculto
- `title` — Título del diálogo
- `message` — Mensaje de confirmación
- `confirmLabel` — Texto del botón confirmar (default: "Eliminar")
- `onConfirm` — Callback al confirmar
- `onCancel` — Callback al cancelar
- `busy` — Estado de carga

### BookSearch
Componente de búsqueda en Google Books API.

**Props:** Ninguno (estado interno)

## Componentes UI Genéricos

### Spinner
Indicador de carga.

**Props:**
- `label` — Texto (default: "Cargando…")

### EmptyState
Estado vacío para listados sin datos.

**Props:**
- `title` — Título
- `message` — Mensaje (opcional)
- `action` — Elemento de acción (opcional)

### Skeleton / SkeletonGrid
Esqueleto de carga para tarjetas.

**Props (SkeletonGrid):**
- `count` — Número de esqueletos (default: 6)

### Navbar
Barra de navegación principal.

**Props:** Ninguno

### ErrorBanner
Banner de error para mostrar mensajes de error.

**Props:**
- `message` — Mensaje de error
- `onRetry` — Callback para reintentar (opcional)
