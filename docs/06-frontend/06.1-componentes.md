# Componentes

## Componentes de Libros

### BookCard
Tarjeta de libro para listados.

**Props:**
- `book` — Objeto libro
- `onEdit` — Callback al editar
- `onDelete` — Callback al eliminar (opcional)

### BookForm
Formulario reutilizable para crear/editar libros.

**Props:**
- `initialData` — Datos iniciales (edición)
- `onSubmit` — Callback al guardar
- `onCancel` — Callback al cancelar

### StatusBadge
Badge de estado del libro.

**Props:**
- `status` — Estado (TO_READ, READING, COMPLETED)

### StarRating
Componente de puntuación por estrellas.

**Props:**
- `rating` — Valor 0-5
- `onChange` — Callback al cambiar (opcional)
- `readonly` — Solo lectura

### ConfirmDialog
Diálogo de confirmación reutilizable.

**Props:**
- `open` — Visible/oculto
- `title` — Título del diálogo
- `message` — Mensaje de confirmación
- `onConfirm` — Callback al confirmar
- `onCancel` — Callback al cancelar
