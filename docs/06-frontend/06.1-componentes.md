### BookBarcodeScanner
Modal de escáner de código de barras (ISBN) para libros. Usa `html5-qrcode`
para acceder a la cámara del dispositivo y detectar automáticamente el código
EAN-13 del libro físico.

**Props:**
- `open` — Visible/oculto
- `onClose` — Callback al cerrar el modal
- `onBarcodeDetected` — Callback al detectar un ISBN válido (recibe el código
  y detiene el scanner automáticamente)

**Flujo:**
1. Usuario clickea botón "📷" en BookCreatePage
2. Se abre modal con vista de cámara
3. El usuario alinea el código de barras dentro del marco de escaneo
4. Al detectar EAN-13 → se dispara `onBarcodeDetected(isbn)`
5. El modal se cierra automáticamente y se detiene la cámara
6. El ISBN se rellena en el campo del formulario
7. Se busca automáticamente en Google Books con ese ISBN
8. Se muestran resultados pre-llenados para el usuario

**Dependencia:** `html5-qrcode` (NPM)

**Consideraciones:**
- Requiere HTTPS en producción (Vercel lo tiene)
- Requiere permiso de cámara del usuario
- En iOS Safari puede requerir que el contenedor de video sea visible
- Se detiene automáticamente tras primera detección exitosa
- Fallback: si no hay cámara o permiso denegado, se muestra mensaje amigable
