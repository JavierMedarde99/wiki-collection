# Navegación

## Estructura de Rutas

```jsx
<Routes>
  <Route path="/" element={<Layout />}>
    <Route index element={<HomePage />} />
    
    {/* Books */}
    <Route path="books">
      <Route index element={<BookListPage />} />
      <Route path="new" element={<BookCreatePage />} />
      <Route path=":id/edit" element={<BookEditPage />} />
      <Route path="search" element={<BookSearchPage />} />
    </Route>
    
    {/* Games */}
    <Route path="games">
      <Route index element={<GameListPage />} />
      <Route path="new" element={<GameCreatePage />} />
      <Route path=":id/edit" element={<GameEditPage />} />
      <Route path="search" element={<GameSearchPage />} />
    </Route>
  </Route>
</Routes>
```

## Layout Principal

```

│                                                         │

```

## Navegación entre Páginas

| Desde | Acción | Hacia |
|-------|--------|-------|
| Home | Click "Books" | BookListPage |
| Home | Click "Games" | GameListPage |
| BookListPage | Click "Add Book" | BookCreatePage |
| BookListPage | Click en tarjeta | BookEditPage |
| BookListPage | Click "Search" | BookSearchPage |
| BookCreatePage | Guardar éxito | BookEditPage |
| BookEditPage | Guardar éxito | BookListPage |
| BookSearchPage | "Add to collection" | BookEditPage |
