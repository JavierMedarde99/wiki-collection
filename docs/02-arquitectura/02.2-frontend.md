# Arquitectura Frontend

## Stack

- **Framework:** React 18.3+
- **Build:** Vite 5
- **Routing:** React Router v6
- **Estilos:** Tailwind CSS 3
- **Estado:** useState, useEffect, useCallback
- **HTTP Client:** Fetch API (custom wrapper)
- **Tipado:** TypeScript 7 (tsx)
- **Testing:** Vitest + React Testing Library

## Patrón de Componentes

- **Componentes funcionales** con hooks
- **Props down, events up** para comunicación padre-hijo
- **Custom hooks** para lógica reutilizable (no implementados actualmente)
- **Estado local** con useState/useEffect

## Comunicación con Backend

```typescript
// Ejemplo: servicio de libros
import { listBooks } from '../api/booksApi';

// Llamada al backend
const books = await listBooks({ page: 0, size: 12, state: 'READING' });
```

La configuración de proxy en Vite redirige `/api` a `http://localhost:8080`.

## Modelo de Datos (Frontend)

### Book (Libro)

```typescript
interface Book {
  id: string;
  externalId?: string;
  title: string;
  author: string;
  descripcion?: string;
  pages?: number;
  type: BookType;       // MANGA | NOVEL | GRAPHIC_NOVEL
  state: BookState;     // TO_READ | READING | COMPLETED
  comment?: string;
  start?: number;       // 0-5
  startDate?: string;
  endDate?: string;
  frontpage?: string;
}
```

### Game (Videojuego)

```typescript
interface Game {
  id: string;
  externalId?: string;
  title: string;
  platform: GamePlatform;  // PC | PS2 | PS3 | WII_U | SWITCH
  thumbnailUrl?: string;
  status: GameStatus;      // PLAYING | COMPLETED | WISHLIST | ABANDONED
  userRating?: number;     // 1-5
  comment?: string;
  dateAdded?: string;
  dateCompleted?: string;
  externalSource?: string;  // RAWG | FreeToGame
  steamAppId?: string;
  obtainPlatinum?: boolean;
}
```

### BoardGame (Juego de Mesa)

```typescript
interface BoardGame {
  id: string;
  title: string;
  description?: string;
  yearPublished?: number;
  minPlayers?: number;
  maxPlayers?: number;
  minPlaytime?: number;
  maxPlaytime?: number;
  publisher?: string;
  designers?: string[];
  categories?: string[];
  mechanics?: string[];
  imageUrl?: string;
  thumbnailUrl?: string;
  bggRating?: number;
  bggId?: string;
  status: BoardGameStatus;  // OWNED | WISHLIST
  notes?: string;
  dateAdded?: string;
}
```

### MagicCard (Carta Magic)

```typescript
interface MagicCardResponse {
  id: string;
  scryfallId?: string;
  oracleId?: string;
  name: string;
  language?: MagicLanguage;
  releaseDate?: string;
  manaCost?: string;
  convertedManaCost?: number;
  type?: string;
  text?: string;
  power?: string;
  toughness?: string;
  loyalty?: string;
  colors?: string[];
  colorIdentity?: string[];
  keywords?: string[];
  rarity?: string;
  setCode?: string;
  setName?: string;
  artist?: string;
  frame?: string;
  borderColor?: string;
  layout?: string;
  legalities?: Record<string, string>;
  priceUsd?: string;
  priceEur?: string;
  imageUrl?: string;
  imageLargeUrl?: string;
  artCropUrl?: string;
  condition?: MagicCondition;
  isFoil?: boolean;
  quantity?: number;
  notes?: string;
  dateAdded?: string;
}
```

**Nota:** El backend usa `author` como string singular, mientras que Google Books devuelve `authors` como lista. El frontend normaliza esto al recibir datos de la API externa.
