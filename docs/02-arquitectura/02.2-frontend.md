# Arquitectura Frontend

## Stack

- **Framework:** React 18+
- **Build:** Vite 5
- **Routing:** React Router v6
- **Estilos:** Tailwind CSS 3
- **Estado:** useState, useEffect, useCallback
- **HTTP Client:** Fetch API (custom wrapper)
- **Tipado:** TypeScript 5

## Patrón de Componentes

- **Componentes funcionales** con hooks
- **Props down, events up** para comunicación padre-hijo
- **Custom hooks** para lógica reutilizable (no implementados actualmente)
- **Estado local** con useState/useEffect

## Comunicación con Backend

```typescript
// Ejemplo: servicio de libros
import { listBooks } from '../api/booksApi';

// Llamada al backend
const books = await listBooks({ page: 0, size: 12, state: 'READING' });
```

La configuración de proxy en Vite redirige `/api` a `http://localhost:8080`.

## Modelo de Datos (Frontend)

El frontend usa un modelo `Book` diferente al backend:

```typescript
interface Book {
  id: string;
  externalId?: string;
  title: string;        // String (no lista)
  author: string;       // String singular (no lista de autores)
  descripcion?: string;
  pages?: number;
  type: BookType;       // MANGA | NOVEL | GRAPHIC_NOVEL
  state: BookState;     // TO_READ | READING | COMPLETED
  comment?: string;
  start?: number;       // 0-5
  startDate?: string;
  endDate?: string;
  frontpage?: string;
}
```

**Nota:** El backend usa `author` como string singular, mientras que Google Books devuelve `authors` como lista. El frontend normaliza esto al recibir datos de la API externa.
